I'm **CREEPY** — self-taught, building in public, and not slowing down.

I started with curiosity and a browser console. Now I work across the full stack:
React frontends, Node backends, databases, containerized deployments, game tooling — the whole picture.

I don't wait until I'm "ready." I build first, figure it out, and improve in the next version.
That's the only philosophy that's ever actually worked.

> **Currently:** Assembling my portfolio project by project. Every commit is public. Every mistake is a lesson.
